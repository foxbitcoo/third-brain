# 产品截图

2026 年 10 月 21 日使用当前个人原型页面重新截图。所有内容为手工编写的 mock 数据，加载真实界面组件；未连接办公数据、模型或查数服务。公开版的可运行能力以 README 中「公开版 Alpha」为准。

| 页面 | 示意内容 |
| --- | --- |
| 工作概览 | 知识库、入门指南等虚构主线及优先级标签 |
| 业务问答 | 示例问题、已有回答与依据入口 |
| 依据原文 | 原始段落、人物提及和来源定位 |
