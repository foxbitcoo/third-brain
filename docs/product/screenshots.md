# 产品截图

项目记忆、历史工单及工单记忆截图更新于 2026 年 10 月 24 日，其余截图保留 10 月 21 日版本。所有内容为手工编写的 mock 数据，加载真实界面组件；未连接办公数据、模型或查数服务。公开版的可运行能力以 README 中「公开版 Alpha」为准。

| 页面 | 示意内容 |
| --- | --- |
| 工作概览 | 知识库、入门指南等虚构主线及优先级标签 |
| 业务问答 | 示例问题、已有回答与依据入口 |
| 依据原文 | 原始段落、人物提及和来源定位 |
| 历史工单 | 示例提问者／分析者的核账对话、引用图及最新记忆 Tab |
| Agent 流程 | 唯一数值判断、单次查数、多轮分析、人工补充 |
| 看板原图 | 虚构趋势图及分开的统计日和推送时间 |
| 阶段报告 | 部分覆盖、未确认原因和下一步 |
| 项目记忆 | 七段经验卡、方向分类、折叠原文；虚构示例，无实际模型注入 |
| 工单记忆 | 本单产出与相关方法入口；虚构案例，无模型回答或注入记录 |

图中的 12,000、10,800 和相关日期仅用于说明交互，不来自真实业务。示例身份不映射真实成员；没有真实文档链接。
