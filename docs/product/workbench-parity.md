# 公开工作台与本地实现对齐验收

## 问题

公开 main 的默认入口仍是旧 Alpha，产品文档使用了新版示意截图，导致独立安装者看到的界面和实际产品不一致。

## 本次范围

1. npm install / npm start 从干净环境构建并启动新版五页工作台；旧入口只保留显式兼容命令。
2. 保留安装者自己的 OAuth、模型设置及本地加密存储，将真实导入后的模型结果接入新版概览、问答与证据。
3. 同步通用的来源关注、会邀/文档版本/原图、看板快照、历史问答引用与富文本时间线、Agent Query 分流及有限循环、报告、Memory 召回与注入审计实现。
4. 缺少配置显示未就绪，流程规范始终可读；不填充维护者数据，不产生虚构运行结果。
5. 扩展配置只允许服务器本地文件路径；查数只执行明确授权并核验的只读方案；浏览页面不触发模型收费。
6. 过滤任何已排除来源及依赖它的派生结论；分析中途来源被排除后，不得返回其结果。
7. 隔离现有私有应用、评测进程、共享技能及并行工作。只向公开仓库发布经扫描的通用实现与虚构示意素材。

## 验证

新增安装集成测试：空环境入口、真实导入模型结果的结构映射（依赖均为离线假服务）、排除来源与跨站拦截。保留并运行原有运行时测试、新工作台完整套件及会邀/文档采集测试；干净 HOME 安装构建、HTTP 回读和浏览器页面检查独立验证。离线查数/模型契约不冒充安装者办公账号连接成功。
